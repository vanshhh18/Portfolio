# Vansh Mittal Portfolio

Personal portfolio showcasing my projects, technical skills, experience, and achievements in AI/ML and software development.

🌐 **Live Portfolio:** [vansh-18-portfolio.vercel.app](https://vansh-18-portfolio.vercel.app/)

## Tech Stack
- React
- Vite
- JavaScript
- Tailwind CSS

## Run Locally

```bash
git clone <your-repository-url>
cd <project-folder>
npm install
npm run dev
```

## Deployment
Deployed using **Vercel**, with automatic deployments from GitHub.
